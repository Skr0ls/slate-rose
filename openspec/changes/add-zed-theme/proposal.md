# Proposal

## Why

Slate Rose needs an installable Zed theme built from the approved shared palette.

## What Changes

Add a deterministic Zed adapter and a theme-only extension. Apply the editor colors and documented syntax captures while preserving Zed's shell defaults.

## Capabilities

### New Capabilities

- `zed-theme` generates and packages the initial Slate Rose theme for Zed.

### Modified Capabilities

None.

## Impact

The shared generator CLI, a Zed extension package, targeted tests and a CI drift check.
