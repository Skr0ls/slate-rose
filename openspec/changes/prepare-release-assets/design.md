# Design

Add a read-only job after the existing package jobs. Download the named
VS Code, JetBrains Python 3.14 and Zed artifacts from the same workflow run.
Use the validated Zed directory as the input to a deterministic standard
library ZIP containing the manifest, theme, license and guide at their
installable paths. Collect exactly the VSIX, JAR and Zed ZIP as
`slate-rose-release-assets`.

Document manual draft release creation from an approved tag on main.
Marketplace identity and credentials, automated draft upload and repository
moves remain separately tracked. Refocus the root guide on installation and
navigation while keeping stable package paths.
