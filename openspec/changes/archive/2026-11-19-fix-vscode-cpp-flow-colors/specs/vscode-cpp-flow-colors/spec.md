## ADDED Requirements

### Requirement: C++ conditional and loop colors

The VS Code theme SHALL map the C++ TextMate scopes `keyword.control.if.cpp` and `keyword.control.for.cpp` to the approved control foreground.

#### Scenario: C++ condition and loop use the control foreground

- **WHEN** VS Code assigns either verified C++ scope and TextMate supplies the foreground
- **THEN** Slate Rose uses the control foreground
