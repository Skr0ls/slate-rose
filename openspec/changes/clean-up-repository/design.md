## Context

The active list includes completed checklists and changes whose acceptance is
tracked outside the checklist. Review evidence already lives by editor.

## Goals / Non-Goals

Keep open work easy to find and retain the records needed to understand shipped
behavior. Release automation and marketplace submissions are separate work.

## Decisions

Archive by editor or capability after verifying task completion, integration,
and the acceptance in the original scope. Sync delta requirements before
moving change folders. Update links from the backlog and inside the archive.

Keep package guides as the source for installation and builds. Link the
existing evidence from a shared index and leave it at its current paths.

## Risks / Trade-offs

Moving a change can invalidate incoming and outgoing relative links. Check
both directions after each batch. Keep explicitly outstanding acceptance in
the backlog.
