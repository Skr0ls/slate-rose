## Why

Completed work still appears in the active OpenSpec list, and installation
instructions and review evidence are harder to find than they need to be.

## What Changes

- Archive accepted changes in batches and carry their durable requirements
  into the main specs.
- Make the backlog point to current work and keep historical evidence navigable.
- Use the root README as the installation entry point and add a review index.

## Capabilities

### New Capabilities

None.

### Modified Capabilities

None. Existing delta requirements move into main specs as their changes close.

## Impact

The cleanup affects OpenSpec records and documentation. Package paths and
build and publication behavior stay stable.
