# Proposal

## Why

The C++ baseline inspector found that `if` and `for` use the generic keyword color. Both have distinct C++ scopes and can use the approved control color.

## What Changes

Add two C++ TextMate selectors and a focused regression check.

## Capabilities

### New Capabilities

- `vscode-cpp-flow-colors` — C++ control colors for the verified conditional and loop scopes.

### Modified Capabilities

None.

## Impact

VS Code generator, generated theme, and regression test.
