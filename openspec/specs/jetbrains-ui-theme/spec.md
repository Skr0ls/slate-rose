# jetbrains-ui-theme Specification

## Purpose

Apply the approved Slate Rose shell colors to JetBrains Islands while preserving native IDE layout and interaction patterns.

## Requirements

### Requirement: Approved Islands shell
The theme SHALL inherit Islands Dark, pair with the existing Slate Rose editor scheme and use only approved core colors. Outer framing, gaps, toolbar, stripes and status bar SHALL use surface2; tool-window islands and tab strip SHALL use bg; selected tabs SHALL use surface with an accent border. Other states SHALL inherit the host.

#### Scenario: Applying the theme
- **WHEN** Slate Rose is selected in Rider
- **THEN** the shell follows the approved allocation and the editor scheme is associated
- **AND** font settings, native geometry, controls, project-color preferences and syntax mappings are not changed by the theme

### Requirement: Deterministic UI generation
The CLI SHALL build and read-only check JetBrains UI output through a separate host target. Existing commands SHALL retain their behavior. Invalid inputs and output aliases of selected/canonical palettes SHALL fail before writes; missing or stale checks SHALL fail without mutation.

#### Scenario: Independent output
- **WHEN** unchanged inputs are built twice for the UI target
- **THEN** generated bytes are identical and existing editor artifacts remain unchanged
- **AND** checking missing/stale output does not create or rewrite files
